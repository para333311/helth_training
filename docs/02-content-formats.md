# 02. 콘텐츠 형식 (글 / 이미지 / 영상)

## 원칙: 텍스트가 주력, 이미지·영상은 보조

텔레그램은 **텍스트 알림이 그대로 잠금화면에 뜬다.** 이게 인스타·유튜브 대비 이 채널의 최대 무기다.
아침 6:30에 잠금화면에 "🟢 누워서 다리 들기 20번"이 뜨는 것 — 이게 자극의 본체다.

이미지·영상을 첫 줄에 붙이면 **미리보기에서 텍스트가 잘린다.** 자극 문구가 알림에서 사라진다.
→ **미션 글은 무조건 텍스트 우선.** 시각 자료는 별도 메시지나 하단에.

---

## 형식 1. 텍스트 미션 (매일 06:30) — 주력

**고정 템플릿을 절대 바꾸지 않는다.** 형식이 고정돼야 스캔 속도가 붙고, 습관이 된다.

```
🗓 D+12 · 목요일 · 유산소

계단 3층 왕복

🟢 1층 왕복 (1분)
🟡 3층 왕복 (5분)
🔴 3층 왕복 ×3 (12분)

엘리베이터 앞에서 3초만 고민해보세요.

────────
하나라도 했으면 💪
```

**규칙**
- 5~8줄. 스크롤 없이 알림 확장만으로 다 읽혀야 한다.
- 첫 줄에 `D+n` — 시즌 진행도를 매일 각인
- 마지막 줄은 **항상** 인증 유도 문구
- 이모지는 난이도 표시 3개 + 💪 정도로 절제. 많아지면 광고처럼 보인다.

---

## 형식 2. 초단기 자극 텍스트 (낮/저녁) — 3줄

귀찮음이 최고조인 시간대(점심 후, 퇴근 직후)에 던지는 짧은 글.
**정보가 아니라 방아쇠**가 목적이다.

```
지금 앉아 있죠.

일어나서 스쿼트 10개.
30초면 끝납니다. 지금.
```

이 형식은 만들기 쉽고 반응이 좋다. 재고를 30개쯤 쌓아두고 돌려 쓴다.

---

## 형식 3. 이미지 — 3종만 쓴다

| 종류 | 용도 | 제작 난이도 |
|---|---|---|
| **자세 카드** | 동작 1개를 정지 이미지 + 화살표로 설명 | 중 |
| **게이지 카드** | 주간 결산 진행도 시각화 | 하 |
| **문장 카드** | 자극 문구 한 줄만 크게 | 하 |

**제작 규칙**
- 정사각형(1080×1080) 또는 세로(1080×1350). 텔레그램 인앱 뷰에서 잘 보인다.
- 글자는 **최대 12자**. 축소 미리보기에서도 읽혀야 한다.
- 색 2개 + 검정/흰색으로 고정. 매번 톤이 바뀌면 채널 정체성이 흐려진다.
- 배경 이미지에 텍스트를 얹지 말 것 — 단색 배경 + 큰 글자가 훨씬 잘 읽힌다.

> 게이지 카드는 이미지 대신 **텍스트 블록(▓░)** 으로 대체해도 충분하다. 오히려 제작 부담이 없어 오래간다.

---

## 형식 4. 영상 — GIF와 짧은 영상만

**긴 영상은 만들지도, 올리지도 않는다.** 채널 톤과 안 맞고, 제작 부담으로 채널이 죽는다.

### 4-1. 자세 GIF (5~8초, 무음, 반복 재생)

가장 가치가 높은 시각 자료다. 텔레그램은 GIF를 자동 반복 재생하므로 동작 하나를 보여주기에 최적.

- 5~8초, 동작 2~3회 반복
- 무음 (지하철·사무실에서도 열어볼 수 있어야 함)
- 화면 안에 텍스트로 핵심 주의점 1개만 (예: `무릎이 발끝보다 앞으로 X`)
- 주 2~3회면 충분. 매일 만들 필요 없다.

### 4-2. 세로 숏폼 (15~30초)

주말 챌린지 소개 정도에만. 텔레그램 `sendVideo`로 올리되 **자막 필수** (무음 시청 전제).

### 4-3. 비디오 노트 (동그란 영상, 최대 60초)

텔레그램 고유 포맷. "혼자보는" 컨셉과 은근히 잘 맞는다 — 다듬어지지 않은, 개인적인 느낌.
운영자가 실제로 운동하는 모습을 30초 찍어 올리면 신뢰도가 크게 오른다. **월 1~2회 정도만.**

## 형식 5. 텔레그램 고유 기능 활용

| 기능 | 활용법 |
|---|---|
| **이모지 리액션** | 오운완 인증의 1차 수단. 채널 설정에서 💪🔥😮‍💨 3개만 남기면 인증이 명확해진다 |
| **투표(Poll)** | "오늘 몇 단계 했나요?" 🟢/🟡/🔴 → 익명 인증 + 즉시 통계 |
| **퀴즈 모드** | "플랭크 30초 소모 칼로리는?" 형식의 상식 콘텐츠 |
| **메시지 고정** | 핀 메시지 = 규칙 + 현재 시즌 진행도 (주 1회 갱신) |
| **댓글 그룹** | 오운완 한 줄 인증 공간 |
| **예약 발송** | 주말에 일주일치 미션을 미리 예약 → 운영 부담의 90%가 사라진다 |

> **예약 발송이 이 채널의 생존 전략이다.** 일요일 저녁 1시간에 다음 주 7일치 미션을 다 예약해두면, 평일엔 댓글 대응만 하면 된다.

### 투표를 이용한 인증 (강력 추천)

```
오늘 어디까지 했나요?

🟢 귀찮음 모드 했다
🟡 보통 모드 했다
🔴 여유 모드 했다
😮‍💨 오늘은 못 했다
```

- 익명 투표 → **부담 0**
- 마지막 선택지에 "못 했다"를 **반드시 넣는다.** 못 한 사람도 채널과 상호작용하게 만들어야 이탈하지 않는다.
- 결과가 그대로 통계가 되어 다음 날 콘텐츠 소재가 된다 ("어제 68%가 🟢을 골랐습니다")

---

## 안 하는 것

명시적으로 배제해야 컨셉이 유지된다.

- ❌ 몸 사진 / 바디프로필 / 전후 비교 사진 → "혼자보는" 컨셉 파괴
- ❌ 특정 체중·체지방률을 목표로 제시 → 부담과 비교를 유발
- ❌ 보조제·기구 판매 링크 → 초반에 넣으면 신뢰가 즉사한다
- ❌ 10분 넘는 루틴 → 이 채널의 정체성이 아님
- ❌ 매일 체중 공개 → 주 1회 원칙 위반
