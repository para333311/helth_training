# 05. 장기 유지 구조

대부분의 텔레그램 채널은 콘텐츠가 부족해서가 아니라 **운영자가 지쳐서** 죽는다.
이 문서는 "3개월 뒤에도 돌아가는가"에만 집중한다.

---

## 원칙 1. 12주 시즌제로 끊는다

무한 연재는 운영자와 구독자 양쪽을 지치게 한다.

```
시즌 1 (12주) → 1주 휴방 → 시즌 2 (12주) → …
```

**시즌제의 이점**
- 운영자에게 **합법적인 휴식**이 생긴다 (휴방 주에 다음 시즌 콘텐츠 제작)
- 신규 구독자에게 **명확한 진입점**이 생긴다 ("시즌 3 시작합니다, 지금 들어오세요")
- 중도 이탈자에게 **재진입 명분**이 생긴다 ("지난 시즌 실패했어도 이번엔 처음부터")
- 시즌마다 테마를 바꿔 매너리즘을 피한다 (시즌1: 3kg / 시즌2: 계단 오르기 / 시즌3: 아침 루틴)

**시즌 캘린더**
| 주차 | 이벤트 |
|---|---|
| 1주 | 시즌 오픈, 규칙 재공지, 체중 기준점 기록 |
| 4주 | 1/3 지점 중간 점검, 리셋 데이 |
| 8주 | 2/3 지점, 이탈자 복귀 캠페인 |
| 12주 | 시즌 결산, 완주자 발표(익명 인원수), 다음 시즌 예고 |
| 13주 | **휴방** — 다음 시즌 콘텐츠 일괄 제작 |

## 원칙 2. 배치 제작 + 예약 발송 (가장 중요)

**매일 그날 아침에 콘텐츠를 쓰는 순간 채널은 3주 안에 죽는다.**

텔레그램은 메시지 예약 발송을 기본 지원한다 (전송 버튼 길게 누르기 → Schedule Message).

**일요일 저녁 루틴 (60~80분)**
```
20:00  다음 주 미션 7개 작성           30분
20:30  낮 콘텐츠 5개 작성 (재고에서 선별)  15분
20:45  밤 체크인 7개 (템플릿 복붙)       10분
20:55  전부 예약 발송 등록              15분
21:10  주간 결산 발행                   10분
```

이렇게 하면 **평일에는 댓글 대응만** 하면 된다. 하루 5분.

봇으로 자동화하는 경우 예약 대신 크론으로 `sendMessage` 를 돌린다:
```
30 7  * * *  아침 미션
30 12 * * 1-5 낮 자극
0  22 * * *  밤 체크인
0  21 * * 0  주간 결산
```
(서버 타임존을 KST로 맞추거나 UTC 기준으로 환산할 것)

## 원칙 3. 콘텐츠 재고를 쌓는다

**"만들어서 바로 쓴다"가 아니라 "쌓아둔 걸 꺼내 쓴다".**

| 재고 항목 | 목표 개수 | 소진 속도 | 확보 시점 |
|---|---|---|---|
| 3단 미션 | 84개 (12주치) | 주 7개 | 시즌 시작 전 최소 30개 |
| 귀찮음 응급처치 | 40개 | 주 5개 | 초기에 20개 |
| 자세 GIF | 20개 | 주 2~3회 (재사용) | 매달 3~4개씩 추가 |
| 근육 상식 퀴즈 | 30개 | 주 2개 | 초기에 10개 |
| 270kcal 카드 | 30개 | 주 2~3개 | 초기에 15개 |

**재사용은 죄가 아니다.** 3~4주 지난 미션을 다시 올려도 아무도 눈치채지 못한다.
특히 자세 GIF는 20개만 있으면 사실상 무한히 돌려 쓸 수 있다.

레포 구조:
```
content/
  missions/       # 미션 재고 (JSON/MD)
  quick-fixes/    # 귀찮음 응급처치
  quizzes/        # 퀴즈
  samples/        # 발행 예시
```

## 원칙 4. 하루 최소 발행선을 정해둔다

지치는 날은 반드시 온다. 그때 **"아무것도 안 올리는 것"과 "최소치를 올리는 것"의 차이**가 채널 생명을 가른다.

**최소 생존 모드 (하루 2분)**
```
07:30  🟢 스쿼트 10개. 끝.
22:00  했으면 💪
```

이 두 줄만 올려도 채널은 살아있다. 완벽한 콘텐츠를 못 만들겠으면 이걸 올린다.
**절대 안 되는 건 하루를 통째로 비우는 것이다** — 한 번 비면 다음 날 비우기가 훨씬 쉬워진다.

---

## 원칙 5. 지표는 3개만 본다

| 지표 | 확인 주기 | 건강한 수준 | 위험 신호 |
|---|---|---|---|
| **인증률** (💪 ÷ 조회수) | 주간 | 15~30% | 10% 미만 3주 지속 → 미션 난이도 과다 |
| **조회수 유지율** | 주간 | 구독자의 40%+ | 하락 지속 → 발행 시간대 재검토 |
| **구독 순증** | 주간 | 시즌 중 완만한 증가 | 순감 → 발행 빈도 과다 의심 |

구독자 수보다 **인증률이 훨씬 중요한 지표다.** 1,000명 중 30명 인증하는 채널보다 200명 중 60명 인증하는 채널이 건강하다.

## 원칙 6. 번아웃 방지 장치

| 장치 | 내용 |
|---|---|
| **일요일 = 운영자도 쉬는 날** | 결산 1개만 발행. 미션은 스트레칭으로 고정 |
| **휴방 주 공식화** | 시즌 사이 1주는 아예 쉰다. 사전 공지하면 이탈 없음 |
| **완벽주의 금지** | GIF 못 만들면 텍스트로 대체. 형식보다 연속성이 중요 |
| **댓글 응답 시간 고정** | 하루 1번, 저녁에 몰아서. 실시간 대응하면 오래 못 간다 |
| **재고 잔량 알림** | 미션 재고 14개 미만이면 보충 신호 |

## 원칙 7. 확장은 천천히, 순서대로

되는 걸 확인한 다음에만 다음 단계로 간다.

```
1단계  채널만 (1~2주)          — 매일 발행이 되는지 검증
2단계  + 댓글 그룹 (구독 100명~) — 커뮤니티가 붙는지 검증
3단계  + 봇 스트릭 (5주차~)     — 개인화가 필요한지 검증
4단계  + 시즌 2 테마 확장        — 반복 가능한지 검증
```

**절대 하지 말 것:** 1일차에 봇부터 만들기. 구독자 0명일 때 스트릭 시스템을 짜는 건 가장 흔한 실패 경로다.
채널이 2주 연속 발행에 성공하는 걸 먼저 증명해야 한다.

---

## 원칙 8. 수익화는 시즌 2 이후에

초기에 광고·제휴를 넣으면 신뢰가 즉사한다. 넣더라도 컨셉과 맞는 것만.

- ⭕ 시즌 완주자용 자체 PDF 루틴집
- ⭕ 컨셉에 맞는 소규모 제휴 (홈트 매트, 저칼로리 식품)
- ❌ 보조제 광고 남발
- ❌ "3주만에 -5kg" 류의 과장 마케팅 제휴 (채널 신뢰도와 정면 충돌)
