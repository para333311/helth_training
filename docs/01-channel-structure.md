# 01. 채널 구조 설계

## 컨셉 한 줄

> **혼자보는 운동** — 남한테 보여주려고 하는 운동 말고, 나만 아는 오운완.

헬스 인플루언서 계정과의 차별점은 **"부끄러움이 없다"** 는 점이다.
몸 사진도, 3대 중량도, 헬스장 인증샷도 요구하지 않는다.
"오늘 스쿼트 10개 했다"만으로 오운완이 성립하는 공간.

이 컨셉이 곧 인증 시스템의 설계 원칙이 된다. **인증의 마찰을 0에 가깝게 만드는 것**이 전부다.

---

## 채널이냐 봇이냐: 채널 + 댓글그룹 + 봇 하이브리드

셋 중 하나를 고르는 게 아니라, 역할을 나눠서 셋 다 쓴다.

| 구성 요소 | 역할 | 왜 필요한가 |
|---|---|---|
| **채널** (공개) | 콘텐츠 발행 (1:다 방송) | 알림이 확실히 뜨고, 검색·공유로 유입이 생김 |
| **댓글 그룹** (채널에 연결) | 오운완 인증, 잡담 | 채널 글에 바로 댓글이 달려 커뮤니티가 생김 |
| **봇** (@xxx_bot) | 스트릭 계산, 리마인더, 랜덤 미션 | 개인화 — 채널이 못 하는 걸 담당 |

### 시작 순서 (중요)

한 번에 다 만들면 운영이 무너진다. 이 순서로 간다.

1. **1~2주차:** 채널만. 매일 미션 + 밤 체크인. 인증은 이모지 리액션.
2. **3~4주차:** 댓글 그룹 연결. 댓글로 "D+n" 인증 시작.
3. **5주차~:** 봇 투입. 스트릭 자동 계산 + 저녁 리마인더.

봇을 1일차에 만들지 말 것. 구독자 0명일 때 봇 코드 짜는 건 가장 흔한 실패 경로다.

## 하루 발행 리듬 (3회 고정)

시간을 고정해야 습관이 붙는다. 하루 3번, 각각 역할이 다르다.

| 시간 | 이름 | 길이 | 목적 |
|---|---|---|---|
| **07:30** | 오늘의 미션 | 5~8줄 | 하루의 과제를 준다 |
| **12:30 또는 18:00** | 귀찮음 응급처치 | 2~4줄 | 흔들릴 타이밍에 재점화 |
| **22:00** | 오운완 체크인 | 3줄 + 리액션 | 인증 회수 |

> 아침 미션과 밤 체크인은 **절대 거르지 않는다.** 낮 콘텐츠는 바쁘면 생략 가능.
> 하루 2개는 유지 가능한 최소치이고, 3개가 이상적이다.

## 난이도 3단 구조 (이 채널의 핵심 장치)

매일 미션은 **항상 3단계로 제시**하고, **어느 걸 해도 오운완으로 인정**한다.

| 표시 | 이름 | 소요 | 대상 |
|---|---|---|---|
| 🟢 | 귀찮음 모드 | 1~2분 | 오늘 진짜 아무것도 하기 싫은 날 |
| 🟡 | 보통 모드 | 5~8분 | 평범한 날 |
| 🔴 | 여유 모드 | 15분 | 의욕 있는 날 |

이 구조가 하는 일:
- **이탈 방지** — "오늘은 못 하겠다"는 선택지가 사라진다. 🟢은 누워서도 된다.
- **죄책감 제거** — 🟢 해도 스트릭이 끊기지 않는다. 이게 장기 유지의 전부다.
- **성장 여지** — 같은 사람이 3주 뒤 🟡을 고르기 시작한다.

핀 메시지에 반드시 명시할 문장:
> **🟢만 해도 오운완입니다. 진심입니다.**

## 3kg 프로젝트 (12주 시즌제)

채널을 무한정 굴리면 신규 유입이 붙을 곳이 없다. **12주 시즌**으로 끊는다.

- **목표:** 12주 −3kg
- **근거:** 체지방 3kg ≈ 약 23,000kcal. 84일로 나누면 **하루 약 270kcal 적자**.
- **270kcal의 실감나는 환산** (콘텐츠로 계속 재활용):
  - 밥 반 공기 덜 먹기
  - 빠르게 걷기 40분
  - 라떼 1잔 → 아메리카노
  - 야식 안 먹기 (이거 하나면 대부분 끝)

**핵심 메시지:** 운동만으로 3kg 빼는 건 비효율이다. 이 채널의 운동 미션은 **"습관 스위치"** 이고, 감량의 주력은 하루 270kcal 적자다. 이걸 솔직하게 말하는 게 오히려 신뢰를 만든다.

### 주지표는 체중이 아니라 완료 일수

체중은 하루 단위로 ±1kg씩 출렁여서 매일 재면 의욕만 깎인다.

- **매일 추적:** 오운완 완료 일수 (스트릭)
- **주 1회만 추적:** 체중 — **일요일 아침 딱 한 번**
- 게이지는 일요일 결산에만 등장

```
3kg 프로젝트  4주차
▓▓▓░░░░░░░  0.9 / 3.0 kg
완료 22 / 28일
```

## 요일 로테이션

매일 뭘 올릴지 고민하는 순간 채널은 죽는다. 요일을 고정한다.

| 요일 | 테마 | 미션 성격 |
|---|---|---|
| 월 | **리부트** | 주중 가장 쉬운 미션. 월요일 진입장벽 최소화 |
| 화 | **하체** | 스쿼트·런지 계열 (칼로리 소모 최대) |
| 수 | **코어** | 플랭크·데드버그 계열 (누워서 가능) |
| 목 | **유산소 대체** | 계단, 제자리 걷기, 버피 |
| 금 | **상체** | 푸시업·벽푸시업 계열 |
| 토 | **챌린지** | 조금 긴 루틴 or 주간 챌린지 |
| 일 | **리셋 + 결산** | 스트레칭만. 주간 통계 + 체중 게이지 |

일요일을 **의도적으로 쉬는 날**로 만드는 게 중요하다. "쉬는 날조차 채널이 정해준다"는 감각이 죄책감을 없앤다.
