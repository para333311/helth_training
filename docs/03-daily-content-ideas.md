# 03. 매일 올릴 콘텐츠 아이디어 10선

각 아이디어는 **① 무엇인지 ② 왜 먹히는지 ③ 발행 주기 ④ 제작 시간** 기준으로 정리했다.
제작 시간이 5분을 넘는 포맷은 오래 못 간다는 걸 전제로 설계했다.

---

## 1. 오늘의 3단 미션 ⭐ 채널의 뼈대

**무엇:** 매일 06:30, 난이도 3단으로 나뉜 오늘의 운동 하나.
**왜:** "뭘 할지 정하는 것" 자체가 운동을 미루는 가장 큰 이유다. 결정을 대신 내려준다.
**주기:** 매일 (절대 거르지 않음) · **제작:** 3분 · **형식:** 텍스트

> 예시 → `content/samples/daily-mission.md`

---

## 2. 귀찮음 응급처치 (60초 처방) ⭐ 컨셉의 심장

**무엇:** "지금 소파에 누워 있고 아무것도 하기 싫다"는 상태를 그대로 지목하고, 60초짜리 탈출구 하나를 준다.
**왜:** 이 채널이 존재하는 이유가 바로 이 순간이다. 다른 헬스 채널은 의욕 있는 사람에게 말하지만, 여긴 의욕 없는 사람에게 말한다.
**주기:** 주 4~5회 (점심 후 / 퇴근 직후) · **제작:** 2분 · **형식:** 텍스트 3줄

```
소파에서 일어나기 싫죠.

일어나지 마세요. 누운 채로 다리만 20번 들었다 놓기.
그거 했으면 오늘 오운완 처리해도 됩니다.
```

**재고 확보 팁:** 상황별로 20~30개 미리 써두고 랜덤 발행. (지하철 / 야근 / 술 마신 다음날 / 비 오는 날 / 월요일 아침 / 생리 기간 / 감기 기운 …)

## 3. 오운완 체크인 (밤 22:00) ⭐ 인증 회수 장치

**무엇:** 하루를 닫는 짧은 글 + 리액션 또는 투표.
**왜:** 인증은 "요청받아야" 일어난다. 아침 미션만 있고 밤 회수가 없으면 인증률이 절반 이하로 떨어진다.
**주기:** 매일 (절대 거르지 않음) · **제작:** 1분 · **형식:** 텍스트 + 투표

> 예시 → `content/samples/night-checkin.md`

## 4. 자세 GIF 한 개

**무엇:** 오늘 미션에 나온 동작 하나를 5~8초 GIF로. 흔한 실수 1개만 텍스트로 표시.
**왜:** 집에서 혼자 하면 자세가 틀려도 알려줄 사람이 없다. 이 채널이 줄 수 있는 실질적 가치.
**주기:** 주 2~3회 · **제작:** 15분 · **형식:** GIF (무음, 자동반복)

**주의:** 매일 만들려 하지 말 것. 한 번 만든 GIF는 3~4주 뒤 재사용해도 아무도 모른다. 20개만 쌓이면 1년치 재고다.

## 5. 숨은 270kcal (3kg 프로젝트 연계)

**무엇:** 하루 270kcal 적자를 만드는 방법을 매번 다른 각도로 한 줄씩.
**왜:** 운동만으로 3kg 감량은 어렵다는 현실을 인정하면서, 부담 없는 실행 카드를 계속 공급한다. 채널 목표와 일상을 연결하는 고리.
**주기:** 주 2~3회 · **제작:** 2분 · **형식:** 텍스트 2~3줄

```
오늘의 270kcal

편의점 야식 대신 자기.
그게 오늘의 운동보다 3kg에 더 가깝습니다.
```

```
오늘의 270kcal

라떼 → 아메리카노 (약 120kcal)
+ 한 정거장 먼저 내려 걷기 (약 150kcal)
끝. 이게 오늘 몫입니다.
```

## 6. 익명 한 줄 고백

**무엇:** 구독자가 봇 DM으로 보낸 한 줄을 익명으로 채널에 게시. 운영자가 짧게 답한다.
**왜:** "혼자보는" 컨셉과 완벽히 맞는다. 얼굴도 이름도 없이 공감만 오간다. 참여율을 끌어올리는 가장 저렴한 방법.
**주기:** 주 2회 · **제작:** 3분 · **형식:** 텍스트

```
💬 익명 고백

"헬스장 3개월 끊고 4번 갔어요. 
 이제 그 앞을 지나갈 때 고개를 돌립니다."

→ 헬스장 회원권은 원래 그렇게 쓰이는 물건입니다.
   오늘 집에서 스쿼트 10개 하면 4번이 5번이 됩니다.
```

**주의:** 반드시 익명 처리하고, 민감한 신체·건강 정보가 담긴 제보는 게시하지 않는다. 게시 전 본인 동의를 봇에서 한 번 확인하는 게 안전하다.

## 7. 1분 근육 상식 (퀴즈 모드)

**무엇:** 텔레그램 퀴즈 투표로 상식 하나. 정답 해설 2줄.
**왜:** 정보성 콘텐츠 중 제작비가 가장 싸고, 퀴즈 형식이라 참여가 자동으로 붙는다. 채널이 "잔소리만 하는 곳"이 되지 않게 해준다.
**주기:** 주 2회 · **제작:** 3분 · **형식:** 퀴즈 투표

```
Q. 플랭크 1분의 소모 칼로리는 대략?

① 5kcal  ② 20kcal  ③ 50kcal  ④ 100kcal

정답 ①
네, 5kcal입니다. 김밥 한 알도 안 됩니다.
플랭크는 살 빼는 운동이 아니라 자세 잡는 운동이에요.
살은 다음 항목(숨은 270kcal)에서 뺍니다.
```

> 이런 "기대를 배신하는 정답"이 저장·공유를 가장 많이 유발한다.

## 8. 주간 결산 + 3kg 게이지 (일요일)

**무엇:** 지난 7일 통계 + 시즌 진행 게이지 + 다음 주 예고.
**왜:** 시즌제를 체감시키는 유일한 장치. 진행도가 보이면 중도 이탈이 크게 줄어든다.
**주기:** 주 1회 (일요일 21:00) · **제작:** 10분 · **형식:** 텍스트 블록

> 예시 → `content/samples/weekly-report.md`

## 9. 주말 미니 챌린지 (토요일)

**무엇:** 주말 이틀짜리 가벼운 챌린지. "7일 스쿼트" 같은 긴 건 하지 않는다.
**왜:** 주말은 리듬이 깨지는 구간이다. 평일과 다른 형식이 붙어야 이탈을 막는다.
**주기:** 주 1회 · **제작:** 5분 · **형식:** 텍스트 + 리액션 집계

```
🎯 주말 챌린지 · 화장실 스쿼트

이번 주말, 화장실 갈 때마다 스쿼트 5개.
그게 전부입니다.

몇 번 갔는지 세지 마세요. 
일요일 밤에 "했다" 💪 하나만 눌러주세요.
```

## 10. 리셋 데이 / 실패 사면 ⭐ 장기 유지의 안전판

**무엇:** "이번 주 며칠 빠졌어도 오늘부터 D+1로 다시 셉니다"를 공식적으로 선언하는 글.
**왜:** 습관 채널이 죽는 1번 원인은 **연속 기록이 끊긴 사람의 조용한 이탈**이다. 스트릭이 끊긴 순간 채널을 나가버린다. 정기적으로 "리셋해도 된다"고 말해주면 이 이탈이 크게 줄어든다.
**주기:** 2주에 1회 (일요일) · **제작:** 2분 · **형식:** 텍스트

```
🔄 리셋 데이

지난주에 5일 빠지셨나요? 상관없습니다.
오늘부터 다시 D+1입니다.

이 채널엔 실패가 없습니다. 
멈춘 기간이 있고, 다시 시작한 날이 있을 뿐입니다.

내일 아침 6:30에 뵙겠습니다.
```
