# 밤 체크인 예시 (22:00 발행)

인증을 실제로 회수하는 메시지. 짧을수록 좋다.

---

## 기본형

```
🌙 오운완 체크

오늘 미션, 하셨나요?

아래 버튼 하나만 눌러주세요.
```
↑ 이 메시지에는 텍스트가 아니라 **진짜 인라인 버튼**을 붙인다 (`[💪 했다] [😮‍💨 오늘은 못 했다]`).
버튼을 누르면 콜백으로 user_id 가 그대로 오기 때문에, DM 을 따로 열지 않아도
채널에서 한 번 누르는 것만으로 개인 스트릭이 기록된다 (04번 문서 "기술 참고" 참조).

---

## 투표형 (주 2~3회)

```
🌙 오운완 체크

오늘 어디까지 하셨나요?
```
↑ 이 메시지 뒤에 익명 투표 첨부:

| 선택지 |
|---|
| 🟢 귀찮음 모드 했다 |
| 🟡 보통 모드 했다 |
| 🔴 여유 모드 했다 |
| 😮‍💨 오늘은 패스 |

> 마지막 선택지를 반드시 넣는다. 못 한 사람도 누를 게 있어야 다음 날 돌아온다.

---

## 사회적 증거형 (어제 숫자 공개)

```
🌙 오운완 체크

어제 💪 눌러주신 분 87명.
그중 61명이 🟢이었습니다.

다들 최소한만 하고 있습니다.
그래도 다들 하고 있습니다.

오늘은요?

💪 했다  /  😮‍💨 못 했다
```

---

## 못 한 사람 회수형 (주 1회, 인증률 낮은 날)

```
🌙 오운완 체크

오늘 못 하셨어도 이 글은 읽으셨네요.
그거면 아직 안 끝난 겁니다.

지금 침대에 계시면,
누운 채로 다리 20번만 들었다 놓으세요.
40초입니다. 그럼 오늘도 오운완입니다.

💪 지금 했다
😮‍💨 내일 하겠다
```

## 마일스톤형 (7 / 21 / 50 / 84일)

```

일주일 채우신 분들, 축하합니다.

습관이 만들어지기 시작하는 지점이 정확히 여기입니다.
여기서 3주를 더 가면 안 하는 게 이상해집니다.

못 채우신 분들 — 
이 채널엔 실패가 없습니다. 내일 D+1로 다시 시작하시면 됩니다.

💪
```
