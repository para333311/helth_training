# 아침 미션 예시 (06:30 발행)

그대로 복사해서 쓸 수 있는 실제 발행 문구 모음. 형식은 절대 바꾸지 않는다.

---

## 월요일 · 리부트

```
🗓 D+1 · 월요일 · 리부트

의자에서 일어났다 앉기

🟢 5번 (30초)
🟡 15번 (2분)
🔴 30번 + 마지막 10초 버티기 (5분)

월요일입니다. 오늘은 진짜 쉬운 걸로 갑니다.
지금 앉아 계시죠? 그 의자로 하시면 됩니다.

────────
하나라도 했으면 💪
```

---

## 화요일 · 하체

```
🗓 D+2 · 화요일 · 하체

스쿼트

🟢 10번 (40초)
🟡 15번 × 2세트 (3분)
🔴 20번 × 3세트 (7분)

무릎이 발끝보다 많이 나가지 않게,
엉덩이를 뒤로 빼면서 앉으세요.

하체는 몸에서 제일 큰 근육입니다.
같은 시간 대비 칼로리 소모가 가장 큽니다.

────────
하나라도 했으면 💪
```

## 수요일 · 코어 (누워서 가능)

```
🗓 D+3 · 수요일 · 코어

누워서 다리 들기

🟢 10번 (40초)
🟡 15번 × 2세트 (3분)
🔴 15번 × 3세트 + 플랭크 30초 (6분)

오늘 미션은 누운 채로 다 끝납니다.
침대에서 하셔도 됩니다. 진심입니다.

허리가 바닥에서 뜨면 다리를 덜 내리세요.

────────
하나라도 했으면 💪
```

## 목요일 · 유산소 대체

```
🗓 D+4 · 목요일 · 유산소

계단

🟢 1개 층 걸어 올라가기 (1분)
🟡 3개 층 (4분)
🔴 3개 층 × 3회 (12분)

오늘 하루 중 엘리베이터 앞에 서는 순간이 옵니다.
그때 3초만 고민해보세요.

계단 3층이면 대략 15kcal입니다. 적죠.
근데 이건 칼로리 때문에 하는 게 아닙니다.
"고민하고 계단을 택한 나"를 만들려고 하는 겁니다.

────────
하나라도 했으면 💪
```

## 금요일 · 상체

```
🗓 D+5 · 금요일 · 상체

벽 푸시업

🟢 10번 (40초)
🟡 15번 × 2세트 (3분)
🔴 무릎 대고 바닥 푸시업 10번 × 3세트 (7분)

바닥 푸시업이 안 되면 벽으로 하세요.
벽에서 멀어질수록 어려워집니다.
난이도를 발 위치로 조절하시면 됩니다.

금요일입니다. 🟢로 넘어가도 아무도 뭐라 안 합니다.

────────
하나라도 했으면 💪
```

## 토요일 · 챌린지

```
🎯 D+6 · 토요일 · 주말 챌린지

화장실 스쿼트

이번 주말, 화장실 갈 때마다 스쿼트 5개.

주말이 무너지는 게 아니라
주말에 아무것도 안 해서 월요일이 무너지는 겁니다.

────────
참여하면 💪
```
