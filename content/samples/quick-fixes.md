# 귀찮음 응급처치 예시 (낮/저녁 발행)

이 채널의 심장. 상황별로 미리 써두고 랜덤 발행한다.
**3줄을 넘기지 않는다.**

---

## 소파에 누워 있을 때

```
소파에서 일어나기 싫죠.

일어나지 마세요. 누운 채로 다리만 20번 들었다 놓기.
그거 했으면 오늘 오운완 처리하셔도 됩니다.
```

---

## 점심 먹고 나른할 때

```
방금 점심 드셨죠.

지금 일어나서 3분만 걸으세요.
식후 3분 걷기가 혈당 스파이크를 눌러줍니다. 진짜입니다.
```

---

## 퇴근 직후

```
집 도착하셨나요.

옷 갈아입기 전에 스쿼트 10개.
갈아입고 나면 안 하게 됩니다. 지금이 유일한 타이밍입니다.
```

---

## 야근 중

```
아직 회사시죠.

의자에서 일어나 기지개 15초, 종아리 들기 20번.
오늘은 이걸로 인정입니다. 진심으로요.
```

---

## 술 마신 다음 날

```
어제 드셨죠.

오늘은 물 많이 드시고 10분만 걸으세요.
운동 안 하는 게 아니라, 오늘의 미션이 그겁니다.
```

---

## 비 오는 날

```
비 오네요. 나가기 싫으시죠.

원래 나갈 계획 없으셨잖아요.
집에서 스쿼트 15개 하시면 됩니다. 비랑 상관없습니다.
```

---

## 월요일 아침

```
월요일입니다.

오늘 뭐 대단한 거 하실 필요 없습니다.
의자에서 5번 일어났다 앉으세요. 그게 이번 주 시작입니다.
```

---

## 스트릭 끊긴 사람 대상

```
며칠 빠지셨나요.

그래서 오늘도 안 하실 건가요?
빠진 날은 그냥 빠진 날입니다. 오늘 하면 오늘은 한 날입니다.
```

---

## 밤 늦게 (자기 전)

```
지금 눕기 직전이시죠.

눕기 전에 30초만. 벽 짚고 종아리 들기 20번.
자기 전 스트레칭은 다음 날 몸이 다릅니다.
```

---

## 의욕 과다 경고 (가끔)

```
오늘 의욕 넘치시나요?

그럼 딱 🟡까지만 하세요.
첫 주에 🔴 세 번 하신 분들이 둘째 주에 사라집니다.
```

---

## 지하철 / 이동 중

```
지금 서서 가고 계신가요.

손잡이 잡고 발뒤꿈치 들었다 놓기 20번.
아무도 눈치 못 챕니다. 혼자보는 운동이잖아요.
```

---

## 아무것도 안 하고 싶은 날

```
오늘 진짜 아무것도 하기 싫으시죠.

그럼 하지 마세요. 대신 이 글 읽은 걸로 오늘은 접습니다.
내일 아침 6:30에 다시 오세요. 그거면 됩니다.
```

> 마지막 카드가 중요하다. **"안 해도 된다"고 말해주는 날이 있어야** 사람이 채널을 안 나간다.
> 2주에 한 번 정도 섞어 넣는다.
